配置兼容播放器，
但不替你决定看什么

Luma 是一个空壳播放框架，兼容 TVBox 系配置。它不内置、不托管、不分发任何订阅地址或影视源； 所有内容来自使用者自行导入的配置与脚本。

不收集遥测 · 不上传配置 · 不内置账号体系

能做什么

订阅导入

URL、本地文件或内联文本；兼容 JSONC、base64 图片种与 gzip 包装。多个订阅各自独立的收藏、历史与缓存。

源适配

CMS 采集、Python base.spider、JavaScript（drpy2 / 经典 var spider）。jar 站点只识别并屏蔽，不执行。

聚合搜索

一次关键词覆盖当前配置全部站点，按站流式上屏、可中断，失败按原因分组并支持单站重试。

本地反代播放

重写 m3u8 相对分片，透传 UA / Referer / Cookie；失败按退避重连，换线换源由用户决定。

直播与 EPG

解析 m3u / m3u8 并走本地代理，支持多线路切换、XMLTV 节目单与台标。

隐私与诊断

SQLite 单库 WAL 存储；日志按天轮转并脱敏 URL，设置页可查看真实占用并分项清理。

支持范围

能力状态说明
CMS 采集支持主流配置主体，直链 m3u8
Python（base.spider）支持直链型与 proxy?do=py 型
JavaScript（drpy2 / var spider）支持独立 qjs-runner 进程
parses[] 解析池支持type 0 / 1 / 4
直播（lives）支持m3u8 经本地代理重写后播放
jar（csp_* / 全局 spider jar）不支持依赖 Android 运行时，导入即识别并屏蔽
