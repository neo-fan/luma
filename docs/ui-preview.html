字体声明误导
font-family: "Inter", "Segoe UI Variable", …
项目里没有 @font-face、没有外链、没有 @fontsource——"Inter" 从未加载，实际一直回退到 Segoe UI Variable。声明一个不存在的字体，会让人误判字重渲染结果。
改后：移除 "Inter"，显式列出中文回退

虚拟滚动与探针契约冲突

探针依赖 document.querySelectorAll('.vod-card') 能看到全部节点；真虚拟化会只保留视口内的。另外两个探针用 select.select 定位首页站点选择器，替换成自研下拉需同步改探针。

提

Tailwind 与 2955 行既有 CSS + 探针 className 契约

现有 CSS 已自成体系（中性灰阶、图标优先、DSH 风格），探针依赖 20+ 个具体 className 与按钮文案。重写成本与回归风险远大于收益。
