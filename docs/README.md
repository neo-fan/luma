# 文档索引

|---|---|---|---|

| [`../AGENTS.md`](../AGENTS.md) | AI 协作者 / 维护者 | 改动前必须知道的约束与铁律（≤ 20 KB） | 约定变化时，保持精炼 |

> `verification-config.md` 是**本地抓取记录**（含真实地址，gitignore、不随仓库分发），只在本人机器上有意义。

## 约定

- **只放活文档**。一次性结论（竞品评估、UI 走查、逐站实测快照）不随仓库分发，留在 git 历史里。
- 文件名 ASCII kebab 或全大写（根目录规范文件名），标题与正文用简体中文。
- 每篇开头写清「本文职责 + 相关文档」，避免同一件事在两处各写一份。
- 文档里的命令必须能在仓库里直接跑通；改代码路径/命令时同步改文档，否则下次排障会先浪费半小时。
